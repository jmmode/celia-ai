# Recursos visuales de CELIA

Los archivos maestros se almacenarán en:
- `assets/identidad/`: guía visual y guía maestra de CELIA.
- `assets/logos/`: logo oficial de TiviPlay Latino.
- `assets/guias/`: guías aprobadas de instalación.
- `assets/capturas/`: capturas auténticas de Fire TV y Downloader.

**Inventario:** `docs/recursos/MANIFIESTO_RECURSOS_CELIA.md`.

**Estado de carga:** los recursos gráficos figuran actualmente en las fuentes del proyecto CELIA de ChatGPT y en un paquete local para importación; **no suponer que están publicados en GitHub hasta verificar los objetos binarios**.

No generar sustitutos sintéticos de imágenes maestras ni publicar fotografías con datos personales.
