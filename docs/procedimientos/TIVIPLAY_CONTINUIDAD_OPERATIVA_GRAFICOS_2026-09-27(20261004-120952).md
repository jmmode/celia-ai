# TIVIPLAY — CONTINUIDAD OPERATIVA DE PIEZAS GRÁFICAS
**Responsable operativo:** JUMOCOL  
**Marca:** TiviPlay / TiviPlay Latino  
**Fecha de actualización:** 2026-09-27  
**Objetivo:** Mantener continuidad en la generación diaria de piezas promocionales para estados y publicaciones de WhatsApp, conservando identidad visual, datos de contacto y formato.

---

## 1. Contexto operativo

TiviPlay es una marca administrada por JUMOCOL.

Una de las tareas recurrentes del equipo es generar y actualizar diariamente piezas gráficas promocionales de TiviPlay usando como referencia:

- piezas anteriores de la misma marca,
- programación deportiva del día,
- promociones comerciales,
- precios,
- eventos,
- contenido informativo,
- campañas de adquisición y renovación.

La lógica de trabajo no consiste en rediseñar la marca cada día, sino en **mantener una plantilla visual estable y actualizar únicamente el contenido variable**.

---

## 3. Regla principal de continuidad

Cada nueva pieza debe partir del siguiente criterio:

> **Mantener identidad TiviPlay + actualizar contenido del día + conservar logo, WhatsApp, dimensiones y tonos azules.**

No se deben modificar innecesariamente:

- el logo,
- el número de contacto,
- la proporción de la pieza,
- la identidad azul,
- la jerarquía comercial,
- la legibilidad móvil.

---

## 4. Flujo diario recomendado

### Paso 1 — Recibir referencia
El usuario entrega una imagen base o una pieza con contenido actualizado, por ejemplo:

- programación deportiva,
- partidos del día,
- promociones,
- precios,
- estrenos,
- canales,
- eventos.

### Paso 2 — Extraer contenido útil
Identificar únicamente la información que debe pasar a la nueva pieza:

- fecha,
- evento,
- horario,
- equipos,
- torneo,
- promoción,
- precio,
- CTA.

### Paso 3 — Reaplicar identidad TiviPlay
Integrar el contenido dentro de la línea gráfica estable:

- logo TiviPlay,
- fondos en tonos azules,
- títulos claros,
- bloques ordenados,
- buena separación visual,
- WhatsApp visible.

### Paso 4 — Validación antes de generar
Confirmar visualmente:

- [ ] Logo correcto.
- [ ] WhatsApp: **350 265 4745**.
- [ ] Formato vertical 1080 × 1920.
- [ ] Tonos azules.
- [ ] Fecha correcta.
- [ ] Horarios correctos.
- [ ] Contenido legible.
- [ ] CTA visible.
- [ ] Sin textos cortados.
- [ ] Sin alterar la identidad de TiviPlay.

### Paso 5 — Generar pieza
Crear la imagen final lista para:

- Estado de WhatsApp.
- Grupo de WhatsApp.
- Publicación comercial.
- Reutilización en campañas.

---

## 5. Plantilla de instrucción operativa

Usar como prompt base:

> **"Toma esta imagen como referencia de contenido. Genera una nueva pieza para TiviPlay manteniendo el logo oficial de TiviPlay, el número de WhatsApp 350 265 4745, formato vertical 1080x1920 para estado de WhatsApp y la línea visual en tonos azules. Conserva una estética comercial, limpia, profesional y legible desde celular. Actualiza únicamente el contenido principal de acuerdo con la referencia suministrada."**

Cuando se trate de programación deportiva, agregar:

> **"Organiza los partidos por horario y jerarquiza los encuentros principales. Mantén buena legibilidad y no sobrecargues la pieza."**

## 6. Tipos de piezas recurrentes

### 6.1 Programación deportiva
Contenido habitual:

- selección / equipo,
- rival,
- hora,
- torneo,
- canal o referencia de transmisión,
- fecha.

### 6.2 Precios
Debe priorizar:

1. plan,
2. duración,
3. número de dispositivos,
4. precio,
5. WhatsApp,
6. CTA.

### 6.3 Promociones
Estructura recomendada:

1. beneficio principal,
2. oferta,
3. vigencia,
4. llamada a la acción,
5. WhatsApp.

### 6.4 Publicación para grupos de WhatsApp
Además de la imagen se puede generar un copy breve con:

- gancho,
- beneficio,
- llamada a la acción,
- contacto.

Usar estructura:

`TIVIPLAY_[TIPO]_[YYYY-MM-DD]_V01.png`

Ejemplos:

- `TIVIPLAY_PROGRAMACION_2026-09-27_V01.png`
- `TIVIPLAY_PRECIOS_COLOMBIA_2026-09-27_V01.png`
- `TIVIPLAY_PROMO_RENOVACION_2026-09-27_V01.png`

Si se corrige una pieza:

- V01 → primera versión
- V02 → corrección
- V03 → versión final refinada

---

## 9. Criterio de calidad

Una pieza se considera terminada cuando:

- respeta la identidad de TiviPlay,
- tiene información correcta,
- el usuario puede entenderla en menos de 5 segundos,
- el contacto es evidente,
- se visualiza correctamente en móvil,
- no requiere explicación adicional para ser publicada.
